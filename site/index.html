Past versions and release notes

Before the course starts, install Miniforge and check the course folder opens. A slow download on the first morning eats into the first session. Your instructors will have sent the install steps; if you have not seen them, email us below.

Once you have the zip

  1. Unzip it somewhere you can find again, such as your Desktop.
  2. Windows: double-click start-jupyter.bat inside the folder.
  3. macOS and Linux: open a terminal, type cd and a space, drag the unzipped folder onto the terminal window, press Return, then run sh start-jupyter.sh.
  4. The first run builds the course environment and takes a few minutes. Every run afterwards takes seconds.

Mac users: do not double-click the launcher. macOS refuses to run anything that arrived from the internet, and the warning it shows offers only Delete and Close. Starting it from the terminal walks around that entirely. The README.md inside the folder explains this step by step.

If your laptop will not let you install anything

You can still take the course. Everything runs in a web browser through Google Colab, and the README.md inside the zip has the steps. Tell us beforehand if you are on a managed machine, so we know how many people to expect.
